# Axi-Theme 功能对照

核对日期：2026-10-23。

参照站：https://axi404.top/ 。站主公开账号：https://github.com/Axi404 。开源主题：https://github.com/Axi404/Axi-Theme 。

本项目保留独立实现、原有路由、双语界面与 GitHub Pages 自动发布。新增组件根据公开主题的功能与组件目录补齐，未复制站主文章、个人资料、数据、服务配置或组件源码。本文用于说明实际范围，不把主题的所有个人内容插件等同于博客基础功能。

| 参照主题能力 | 本站情况 |
| --- | --- |
| 首页、关于、经历、项目、友链 | 已提供，等待填写自己的内容。 |
| 双语导航、亮暗主题、手机布局 | 已提供。 |
| 博客分类、分页、标签、归档、合集 | 已提供。 |
| 全文搜索 | 使用 Fuse，保持现有搜索体验。 |
| 目录、代码复制、数学公式、图表 | 已提供，MD 与 MDX 共用。 |
| 图片放大 | 已提供；此次补充图集、前后图片切换与键盘操作。 |
| Waline 评论、回复、阅读量 | 前端已接入，等待用户服务地址。 |
| GitHub 贡献图 | 按用户要求移除，同时移除贡献数据抓取。 |
| 站点统计、朋友动态 | 已提供。 |
| RSS、sitemap、页面元数据 | 已提供。 |
| Tabs、Collapse、Spoiler、Aside | 此次新增，含键盘与无脚本降级。 |
| Steps、Timeline | 此次新增。 |
| Card、CardList、Button、Label | 此次新增，对应 CardGrid 与 Badge。 |
| GithubCard、LinkPreview | 此次新增；真实 GitHub 数据与手动填写的链接预览。 |
| ImageGroup、WebVideo、Quote、QRCode | 此次新增，对应 ImageGallery、Video、Quote、QRCode。 |
| 手动目录 | 此次新增 ManualTOC。 |
| 学术成果、项目与工具展示 | 原有结构化配置可填，不携带站主数据。 |

原主题名与本项目提供的兼容名称不代表所有属性完全相同，具体写法请使用本站的组件指南与模板。
